# PDB ID lists

Put here the ID lists exported from the [RCSB Advanced Search](https://www.rcsb.org/search/advanced)
("Download IDs"), as `.txt` or `.txt.gz` files. IDs can be separated by commas,
whitespace or one per line; several files are merged and de-duplicated.

The 17 `rcsb_pdb_ids_3a503b…` lists are the input of the reference run described in
the main README: 164,000 PDB IDs from an RCSB search for X-ray entries at a
resolution of 3.0 Å or better (the query itself was not saved). Remove them, or
move them elsewhere, to build a dataset from your own lists; other files placed
here are ignored by git.
